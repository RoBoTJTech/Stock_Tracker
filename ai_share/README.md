# AI project notes

This folder contains project-specific context for AI coding tools and human handoffs.

## How to use this folder

- Read this file and the relevant topic notes before changing the project.
- Treat current code, tests, and the main project README as authoritative when an old note conflicts with them.
- Add or update stable, topic-based notes when architecture, deployment, testing, or important decisions change.
- Use names such as `deployment.md`, `architecture.md`, `development.md`, and `known-issues.md`.
- Do not put passwords, API keys, private certificates, license files, or other secrets here.
- Do not copy general infrastructure or cross-project notes into this folder; those stay in the central `ai_share` repository.
- Do not date maintained topic files. Git records their history.
- Put historical session handoffs and incident snapshots in `history/`; those files may keep dates because the date is part of their context.
- Keep notes concise and update an existing topic file instead of creating duplicates.
